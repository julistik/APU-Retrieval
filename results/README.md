Результаты экспериментов и материалы для анализа ошибок моделей.

## Файлы

- `completed_test_data.json` — результаты автоматической разметки тестовой выборки;
- `both_errors.csv` — ошибки обеих моделей;
- `only_bert_errors.csv` — ошибки только RuBERT;
- `only_gpt_errors.csv` — ошибки только ChatGPT;
- `model_accuracy_comparison.png` — сравнение качества моделей.
