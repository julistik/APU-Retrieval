# **APU-Retrieval**

### *Ambiguous Phraseological Units Retrieval from Corpus*

Курсовая работа, посвящённая автоматическому определению значения омонимичного фразеологизма в контексте.

В работе рассматривается задача, близкая к Word Sense Disambiguation (WSD): для фразеологизма, имеющего несколько значений, необходимо определить, какое значение реализуется в конкретном контексте.

## Структура репозитория

```text
preprocessing/  — обработка исходного словаря
data/           — словарь и датасеты
notebooks/      — эксперименты и анализ результатов
results/        — результаты экспериментов
```

## Основные этапы работы

1. Обработка и структурирование «Словаря фразеологических омонимов современного русского языка».
2. Формирование датасета на основе примеров из словаря и Национального корпуса русского языка.
3. Обучение модели RuBERT для определения значения фразеологизма в контексте.
4. Сравнение результатов RuBERT и ChatGPT.
5. Анализ ошибок моделей.
