## Файлы

### `bert_experiment.ipynb`
Обучение и оценка модели RuBERT для определения значения омонимичного фразеологизма в контексте.

### `chat_gpt_check.ipynb`
Проверка разметки тестовой выборки с помощью ChatGPT и расчёт метрик качества.

### `error_analysis.ipynb`
Анализ ошибок моделей и сравнение предсказаний RuBERT и ChatGPT.
