**Файл:** `scan.pdf` — скан изначального словаря фразеологических омонимов.

---

## Этапы обработки

### **1. Конвертация PDF → TXT**

**Скрипт:** `pdf_to_txt.py`
**Результат:** `result_pdf_to_txt.txt`

---

### **2. Очистка и нормализация текста**

**Скрипт:** `abs.py`
Функциональность:

* восстановление переносов слов (`пере-  носы → переносы`);
* удаление нумерации страниц;
* удаление повторов заголовков словарных статей;
* удаление указаний на издательство.

**Результат:** `result_abs.py`

---

### **3. Первичное формирование словаря**

**Скрипт:** `glue_json.py`
**Результат:** `result_glue.json`

Формат получаемого файла:

```js
"lemma": "",            // фразеологизм КАПСОМ
"entries": [
  {
    "sense_number": 0,  // номер значения
    "meaning": "",      // толкование
    "grammar": "",      // грамматические признаки
    "examples": "",     // примеры
    "synonyms": "",     // синонимы (если есть)
    "antonyms": ""      // антонимы (если есть)
  }
]
```

---

### **4. Структурирование и разбиение полей**

**Скрипт:** `split.py`
**Результат:** `result_split.json`

Изменения:

* `grammar` → массив строк;
* `examples` → массив вида:

```js
[
  ["example_1", "author_1"],
  ["example_2", ["author_2.1", "author_2.2"]],
  ...
  ["example_n", "author_n"]
]
```

**Результат:** `result_abs.txt`

## Итог

В результате обработки был получен структурированный файл `result_split.json`, который использовался как промежуточная версия словаря перед дальнейшей подготовкой датасета.
